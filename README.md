# GHL Tab Renamer

Chrome extension package and one-line Windows installer. Version 3.4.0.

## Install or update on each Windows PC

Open **PowerShell** (no admin) and paste:

```powershell
irm https://raw.githubusercontent.com/hope-joe-instinct/ghl-tab-renamer-dist/main/install.ps1 | iex
```

The installer downloads the current release, verifies its SHA-256 before changing your files, unpacks it to `%LOCALAPPDATA%\GHLTabRenamer`, and copies that folder path. It does not change Chrome storage or your existing device pairing.

- **First install:** Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, paste the copied folder path, and select it.
- **Update:** Run the same PowerShell line, then click **Reload** on the GHL Tab Renamer card at `chrome://extensions`. Do this on each PC. Chrome does not silently install or reload unpacked extensions.

The public package contains no bundled client inventory. Existing client names in Chrome storage remain; new names are learned from GHL pages you visit. New PCs cannot pair with the sync service until a fresh pairing code is issued. Existing paired PCs keep their tokens.

For a manual download, use the [latest release](https://github.com/hope-joe-instinct/ghl-tab-renamer-dist/releases/latest). The `update.json` manifest holds its pinned ZIP URL and SHA-256. Do not use GitHub's autogenerated "Source code" ZIP, which is only this distribution repository, not the extension.
